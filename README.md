# KDE Video Frame

A lightweight KDE Plasma 6 plasmoid for playing videos directly on the desktop.

## Features

- Video file selection
- Looping playback
- Audio toggle
- Volume control
- Video rotation (0°, 90°, 180°, 270°)
- Optional video frame
- Transparent widget background
- Qt Multimedia / FFmpeg playback
